Get started
  1. Search a game or pick a running program.
  2. Press Start.

Optional: to use your own Discord application, add its ID at the bottom of Settings. Create one at discord.com/developers/applications.

Icons

Search results bring their own cover. To use another one, paste a link, drop or paste an image, or use the image button next to the link box. The crop button on the cover zooms, moves and rotates it.

An ImgBB API key (free at api.imgbb.com) in Settings hosts your own images and program icons so Discord can show them.

Buttons

The link button above the preview adds up to two buttons to your presence. Picking a Steam, GOG or VNDB result fills one in. Other people see them, you don't.

Saved apps

The bookmark button saves the current title, icon and program. Saved apps start the presence by themselves when the program opens, and stop when it closes. Stopping by hand keeps it off until the program is closed and opened again.

My Games

Games you started, saved or added with “Add to My Games” (with a program chosen) show up here, with the time you've played. Play launches the game and shows it on Discord. Click a game to change its banner. Click a game's title, here or in the search results, to see its store page info: description, trailers, screenshots, ratings and details. If Discord is closed, the presence starts when it opens. With several games open, closing the one on Discord brings back the previous one.

Background

Set “When the window closes” to Tray to keep ANY-PRESENCE running. Open it again from the tray icon.

Problems

No presence in Discord: Discord must be open and Activity Status on in Discord's settings.

Slow searches or uploads: try Connection → IPv4 in Settings.
